# TrendRadar v4

لوحة تعرض ما يصعد الآن في App Store وGoogle Play وGitHub، وتُحمَّل تلقائياً بلا اختيار متجر ولا كلمة بحث.

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. في هذا المجلد: `npm install`
3. `npm start`
4. افتح http://localhost:3000

اترك الخادم يعمل. يحفظ لقطة لترتيب المتجرين كل 3 ساعات، ويظهر عمود «تغيّر الترتيب» بعد نحو 20 ساعة من أول تشغيل.

إن فتحت `index.html` مباشرة من جهازك فسيعمل قسم GitHub فقط. للمتجرين أضف عنوان الخادم: `index.html?api=http://localhost:3000`

## المتغيرات
- `PORT` (الافتراضي 3000)
- `COUNTRY` رمز متجر الدولة، مثل `us` أو `sa` أو `ae` (الافتراضي `us`)

## من أين تأتي البيانات
- App Store: قوائم iTunes RSS للترتيب، وiTunes Lookup للتقييم والسعر.
- Google Play: مكتبة google-play-scraper (غير رسمية، وقد تتعطل إذا غيّرت Google صفحاتها).
- GitHub: REST API من المتصفح مباشرة. اختيارياً ضع token في الصفحة لرفع الحد من 60 إلى 5000 طلب في الساعة.

المتجران لا ينشران أعداد التنزيلات، ولذلك لا تُعرض.
